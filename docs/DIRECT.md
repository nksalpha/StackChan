# 서버 없는 직접 연결 펌웨어

NAS 서버를 거치지 않고, 기기가 클라우드 API를 바로 부른다.

```
말하는 동안  기기 ──음성 실시간 전송──▶ Deepgram (인식 + 말 끝 판정)
말 끝나면    기기 ──인식된 문장───────▶ DeepSeek (답변을 조금씩 받음)
문장마다     기기 ──문장──────────────▶ Google TTS (음성) → 바로 재생
```

- 펌웨어: `firmware/out/xiaozhi-stackchan-ko-direct-full.bin`
- 표정: 답변 맨 앞의 감정 태그(`[happy]` 등)를 읽어서 바꾼다.
- 대화 기억: 최근 6번 주고받은 내용까지. 전원을 끄면 지워진다.
- 키는 펌웨어 파일에 들어 있지 않다. 기기 설정 화면에서 넣으면 기기 안(NVS)에 저장된다.
- NAS 서버용 펌웨어(`xiaozhi-stackchan-ko-full.bin`)는 그대로 두었으니 언제든 바꿔 올릴 수 있다.

## 1. API 키 준비

키마다 이 기기 전용으로 새로 만들고, 쓸 수 있는 한도를 걸어 둔다. NAS 서버가 쓰는 키는 그대로 둔다.

### Deepgram
1. https://console.deepgram.com 로그인
2. 프로젝트 → **API Keys** → **Create a New API Key**
3. 이름은 `stackchan-device` 정도로. 권한은 기본(Member)이면 된다.
4. 만들어진 키를 복사해 둔다. 이 화면을 닫으면 다시 볼 수 없다.

### DeepSeek
1. https://platform.deepseek.com 로그인
2. **API keys** → **Create new API key** → 이름 입력 → 복사
3. DeepSeek은 충전식이라 충전한 금액 이상은 나가지 않는다.

### Google Cloud TTS
Google은 결제 수단 등록이 있어야 쓸 수 있다. 무료 사용량(기본 음성인 WaveNet 기준 월 400만 자)을 넘으면 자동으로 청구되니 아래 한도 설정을 꼭 한다.

1. https://console.cloud.google.com 에서 프로젝트를 하나 만든다 (예: `stackchan`).
2. 상단 검색창에 **Cloud Text-to-Speech API** → **사용(Enable)**
3. https://console.cloud.google.com/apis/credentials → **+ 사용자 인증 정보 만들기 → API 키**
   (OAuth 클라이언트, 서비스 계정, "사용자 데이터/애플리케이션 데이터" 안내 마법사는 쓰지 않는다)
4. 만들어진 키의 **키 제한**에서
   - API 제한사항: **Cloud Text-to-Speech API**만 선택
   - 저장
5. 한도 걸기 (둘 다 해 두면 안심)
   - **결제 → 예산 및 알림**: 월 예산을 1달러 정도로 잡고 알림 받기 (알림만 오고 사용을 막지는 않는다)
   - **API 및 서비스 → Cloud Text-to-Speech API → 할당량**: 분당 요청 수를 낮게 (예: 60) 잡아 두면 키가 새도 대량으로 쓰이지 않는다

하루 2시간 대화 기준 예상 사용량은 월 40만 자 정도라 무료 범위 안이다.

## 2. 플래싱

`docs/FLASH_WEB.md`와 같다. 파일만 `xiaozhi-stackchan-ko-direct-full.bin`으로 바꿔서 주소 `0x0`에 올린다.
처음 올리면 Wi-Fi와 키 설정이 모두 비어 있는 상태로 시작한다.

## 3. Wi-Fi와 키 입력 (휴대폰)

1. 기기가 `Xiaozhi-XXXX` Wi-Fi를 띄운다 → 휴대폰으로 연결
2. 자동으로 뜨는 "로그인" 팝업은 닫고(연결은 유지), **Chrome이나 Safari 앱**에서 `http://192.168.4.1`을 연다.
3. 첫 화면(Wi-Fi Config) 한 곳에서 모두 입력한다.
   - 아래 목록에서 사용할 장소의 2.4GHz Wi-Fi를 고르고 비밀번호 입력
   - Deepgram / DeepSeek / Google TTS 키 칸에 복사해 둔 키를 붙여 넣기
   - TTS 음성 이름은 비워 두면 `ko-KR-Chirp3-HD-Achernar`. 다른 목소리는 `ko-KR-Chirp3-HD-Aoede`, `ko-KR-Wavenet-A` 등. 설정한 음성이 거부되면 자동으로 `ko-KR-Wavenet-A`로 바뀐다
4. **Connect** → 키가 먼저 저장되고 Wi-Fi에 연결된다.
5. 기기가 재부팅하고 바로 대화할 수 있는 상태가 된다. "Hi,ESP"로 깨운다.

키가 하나라도 비어 있으면 기기가 시작을 마친 뒤 알아서 다시 설정 모드(`Xiaozhi-XXXX`)로 들어간다.
그 화면에서 키만 넣고 **API 키만 저장**을 누른 뒤 기기를 재부팅하면 된다.
키 칸 옆의 `(저장됨)` / `(없음)`으로 저장 상태를 확인할 수 있고, 비워 둔 칸은 기존 키를 유지한다.

## 4. 측정

`docs/FLASH_WEB.md`의 3번(Console에서 115200 연결)과 같은 방법으로 로그를 받는다. 짧은 질문 5번 정도.

로그에서 보는 줄

| 줄 | 뜻 |
|---|---|
| `LAT vad_end>stt=… stt>tts=… tts>audio=… vad_end>audio=…` | 대화 한 번의 구간별 시간(ms). 서버 펌웨어와 같은 형식이라 바로 비교된다 |
| `LAT llm_headers=… ms` | DeepSeek 요청 → 응답 시작 |
| `LAT llm_first_token=… ms` | DeepSeek 요청 → 첫 글자 |
| `LAT tts http=… total=… packets=… chars=…` | Google TTS 한 문장 합성 시간 |
| `Deepgram connected in … ms` | 음성 인식 연결에 걸린 시간 |

오류가 나면 `DirectProtocol` 태그가 붙은 줄에 이유가 찍힌다 (`DeepSeek status 401` 같은 형태).

## 아직 실제 기기로 확인하지 않은 것

빌드까지는 확인했고, 실제 동작은 첫 테스트에서 확인해야 한다.

- Deepgram 실시간 인식이 `nova-3` + 한국어(`ko`) 조합을 받아 주는지 (서버에서는 같은 조합을 일괄 인식으로 쓰고 있음)
- DeepSeek 모델 이름 `deepseek-flash` (서버 설정에서 가져온 값)
- Google 음성 `ko-KR-Chirp3-HD-Achernar`가 OGG_OPUS 24kHz 요청을 받는지 (거부되면 WaveNet으로 자동 전환)
- 음성 인식 연결 1개 + 답변 1개 + 음성 합성 1개, 암호화 연결 3개를 동시에 여는 메모리 상황

모델 이름이나 음성 이름이 틀리면 로그에 400/404 오류로 바로 드러난다. 그러면 기본값만 바꿔서 다시 빌드하면 된다.

## 기억 메모 (2026-11-07 추가)

스택짱이 아이에 대해 알게 된 것을 짧은 메모(최대 약 600자)로 기기 안에 저장해 두고, 대화할 때마다 참고한다.

- 대화 중에는 메모를 읽기만 한다. 대답이 끝나고 10초 뒤 대기로 돌아가면, 그때 뒤에서 오늘 대화를 반영해 메모를 다시 정리한다. 그래서 응답 속도에는 영향이 없다.
- 로그: 시작할 때 `Memory: N bytes`, 갱신될 때 `Memory updated in … ms` 아래에 새 메모 전문이 찍힌다.
- 보기·고치기: 설정 화면(`Xiaozhi-XXXX` → `http://192.168.4.1`)의 **아이 정보 / 기억 메모** 칸. 처음에 이름, 나이, 좋아하는 것을 미리 적어 두면 첫 대화부터 활용한다. 고친 뒤 **API 키·메모만 저장**. 모두 지우고 저장하면 기억이 초기화된다.
- 주의: 메모는 기기 안에 암호화 없이 저장되고, 대화할 때마다 DeepSeek으로 함께 전송된다.

## 설정 화면 들어가기

어른이 스택짱을 깨운 뒤 **"설정 모드"** 라고 말하면 바로 설정 화면(`Xiaozhi-XXXX`)으로 들어간다. 키, 음성, 기억 메모를 바꿀 때 쓴다. 설정이 끝나면 기기를 재부팅한다.

## 표정과 반응 (2026-11-07 추가)

- 대답: AI가 상황에 맞는 표정을 고르고, 대답 중간에 기분이 바뀌면 문장마다 표정이 바뀐다. 표정은 그 문장을 말하기 시작할 때 바뀐다.
- 상황별: 깨우면 반가운 얼굴(happy), 대답을 기다리는 동안 생각하는 얼굴(thinking).
- 대기 중: 20~45초마다 잠깐 윙크·편안함 등으로 바뀌고, 2분 넘게 혼자 두면 졸린 얼굴(sleepy).
- 터치(화면):
  - 톡 치기 → 기쁨·윙크·사랑·장난 중 하나
  - 두세 번 연달아 → 놀람 또는 쑥스러움
  - 1.5초 안에 네 번 이상 콕콕 → 화남 → 쑥스러움
  - 손을 대고 가만히(0.8초 이상) → 편안한 얼굴, 떼면 사랑스러운 얼굴 (쓰다듬기)
  - 좌우로 문지르기 → 크게 웃음 (간지럼)
- 흔들기: 세게 흔들면 깜짝 놀람 → 헷갈리는(어지러운) 얼굴 → 원래대로
- 만지거나 흔들면 어두워진 화면도 다시 밝아진다.
- 로그: 시작할 때 `Touch chip id 0x..`, `BMI270 ready`, 흔들면 `Shake detected`

## 사진 보기 "이거 뭐야?" (2026-11-10 추가)

아이가 물건을 카메라 앞에 들고 "이거 뭐야?"라고 물으면 스택짱이 한 장 찍어 Claude Haiku 5.5에게 보여 주고, 들은 답을 평소 목소리로 말해 준다.

- 알아듣는 말(띄어쓰기 무시): 이거 뭐야, 이게 뭐야, 이건 뭐야, 이거 뭐지, 이거 뭐게, 뭐가 보여, 뭐 보여, 이거 봐, 이것 좀 봐, 보여 줄게, 이거 무슨 …, 이거 어때, 이거 알아, 이건 뭘까
- 이 말이 들어 있지 않은 대화는 지금처럼 DeepSeek이 대답한다.
- 찍는 순간 놀란 얼굴(surprised)로 바뀐다. 사진은 320×240 JPEG(약 10~20KB)이고 기기에 저장하지 않는다.
- 사진 속 사람이 누구인지, 나이·생김새는 말하지 않도록 지시해 두었다.
- 사진 질문과 답도 대화 기록에 남아서, 이어서 "그거 먹어도 돼?"처럼 물으면 DeepSeek이 앞 내용을 알고 대답한다.

### Claude API 키 준비

1. 플랜 가입 후 7일이 지났는지 확인한다.
2. PC 브라우저에서 claude.ai → Settings → Billing → API credits → Link organization. 조직을 새로 만들거나 고르고 약관에 동의한다. 한 번 연결한 조직은 직접 바꿀 수 없다.
3. https://platform.claude.com → 그 조직에서 워크스페이스를 `stackchan`으로 하나 만들고, 워크스페이스 한도(월 사용 한도)를 낮게 걸어 둔다.
4. 그 워크스페이스에서 API 키를 만들어 복사한다.
5. 기기를 설정 모드로("설정 모드"라고 말하기) 넣고 `http://192.168.4.1`의 **Claude API 키** 칸에 붙여 넣은 뒤 **API 키·메모만 저장** → 재부팅.

키가 비어 있으면 사진 기능만 꺼지고 나머지는 그대로 동작한다. 크레딧은 매달 새로 들어오고 남은 건 넘어가지 않는다. 다 쓰면 결제되지 않고 요청이 실패하며, 그때 스택짱은 "지금은 잘 안 보여"라고 말한다.

예상 비용: 사진 한 번에 입력 약 1,500~2,500토큰(대부분 성격 지시와 대화 기록) + 출력 100토큰 안팎 → 약 $0.0003. 하루 50번이면 월 $0.5 정도.

### 로그

| 줄 | 뜻 |
|---|---|
| `Vision request: …` | 사진 질문으로 알아들음 |
| `CaptureJpeg 320x240 -> N bytes` | 촬영·압축 결과 |
| `LAT vision capture=… headers=… body=…` | 촬영 시간, 요청~응답 시작 시간(ms), 보낸 크기 |
| `LAT llm_first_token=…` / `LAT llm_total=…` | 첫 글자 / 답 끝까지 (평소 대화와 같은 형식) |
| `Claude status 401` | 키가 틀림. 400이면 모델·요청 형식 문제, 429는 한도, 529는 혼잡 |
| `Claude stop_reason=refusal` | 안전 판단으로 거절. 스택짱은 "이건 잘 모르겠어"로 넘어간다 |
